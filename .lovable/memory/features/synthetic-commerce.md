# Synthetic / CGI Commerce Showrooms Memory

## Status
Approved planned rendering track; not operational.

## Product Outcome
Create location-independent interactive commerce showrooms from approved 2D floor plans, style references, product/media inputs, and merchandising configuration.

## Builder Rules
- Generation is conditioned on explicit user inputs and reviewed assets.
- Virtual stores are exempt from local-provider availability and physical-address geocoding requirements.
- Output remains a versioned, owner-hostable Frontiers|3D presentation.
- Generated environments must be labeled as virtual/CGI rather than physical captures.

## Atlas Rules
- Atlas may list eligible virtual showrooms.
- Placement uses map-click coordinates constrained by configured geo-fences rather than a fabricated storefront address.
- Pins use distinct colors or shapes from physical-space listings.
- Search/filter/card copy must expose the virtual nature of the listing.

## Open Specification Needs
- Input schema, generation provider/model, moderation, asset rights, quality acceptance, commerce integrations, pricing, and geo-fence semantics require a dedicated approved spec before implementation.
