# Map Oracle And Outreach Memory

## Product Outcome
Public-source business discovery and enrichment feed a truthful, compliant, auditable outreach funnel introducing Atlas and provider-supported immersive presentation.

## Required Flow
- Places ingestion -> normalized property -> candidate -> website/email enrichment with provenance.
- Controlled promotion -> pending render -> preview/test-to-admin -> explicit prospect send -> queue -> exactly-once delivery trace.
- Preserve suppression, unsubscribe, source, idempotency, confidence, audit, and operator approval.

## Boundaries
- No false inside-tour detection claim.
- No synthetic contact data or suppression bypass.
- No unbounded batch outreach.
- Outreach cannot automatically bind providers, bill, or trigger Stripe.
- Portfolio/Atlas demonstrations must not be represented as custom prospect previews.

## Current Gap
One-at-a-time operation has verified sends. Any automated volume requires an approved targeting, throttle, monitoring, and compliance plan.
